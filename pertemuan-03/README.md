# Pertemuan 3 - Formulir HTML dan CSS Dasar

## Baseline
- Menggunakan hasil pertemuan 2 sebagai dasar pengembangan.
- Menyalin kembali `index.html` dan file gambar profil ke folder `pertemuan-03/` untuk dipakai sebagai template awal.

## Implementasi Formulir
- Elemen form yang digunakan: `form`, `label`, `input`, `select`, `option`, `textarea`, dan `button`.
- Tipe input yang digunakan: `text`, `email`, `number`, `date`, `radio`, dan `checkbox`.
- Atribut validasi yang digunakan: `required`, `minlength`, `maxlength`, `min`, `max`, serta validasi otomatis `type="email"`.

## Pengujian GET dan POST
- Hasil pengujian GET: form dikirim dengan method `GET`, sehingga data tampil sebagai query string pada URL.
- Contoh URL encoding yang ditemukan: spasi diubah menjadi `+` dan karakter `@` menjadi `%40` pada alamat email.
- Hasil pengujian POST: belum diterapkan karena saat itu form masih menggunakan method `GET` dan belum ada server untuk memproses data.

## CSS Dasar
- Selector elemen: `h2`, `h3`, `p`, `ol`, `label`, dan `button`.
- Selector class: `.form-group` dan `.input-form`.
- Selector ID: `#about` dan `#contact`.
- Properti CSS dasar yang digunakan: `background-color`, `color`, `border`, `border-bottom`, `padding`, `margin`, `font-family`, dan `font-weight`.

## Pengujian dan Perbaikan
- Galat yang ditemukan: foto profil tidak muncul karena path file tidak sesuai pada saat diunggah ke GitHub Pages.
- Penyebab galat: perbedaan penulisan huruf besar/kecil pada nama file dan path.
- Perbaikan yang dilakukan: path gambar disesuaikan dan file gambar yang valid dipakai.
- Hasil pengujian ulang: foto berhasil dimuat dan halaman tampil dengan layout yang lebih rapi.
