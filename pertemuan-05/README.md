# Pertemuan 5 - JavaScript Dasar, DOM, Event, dan Validasi Sisi Klien

## Deskripsi
Pada pertemuan ini, halaman profil yang sebelumnya dibuat dengan HTML dan CSS dikembangkan dengan menambahkan interaksi JavaScript. Fokus utamanya adalah navigasi responsif, event handling, dan validasi formulir di sisi klien.

## Cara Menjalankan
Buka berkas `pertemuan-05/index.html` menggunakan browser. Jika diperlukan, gunakan Browser DevTools untuk melihat perilaku DOM dan console.

## Fitur dan Pengembangan
- Navigasi responsif menggunakan tombol hamburger.
- Event `submit` pada formulir ditangani dengan `preventDefault()` agar validasi berjalan sebelum data dikirim.
- Form divalidasi di sisi klien untuk nama, email, semester, tanggal, jenis pesan, topik minat, program studi, dan pesan.
- Umpan balik ditampilkan melalui elemen `#formFeedback` dengan status error atau sukses.

## Pengujian
Direalisasikan melalui skenario uji yang mencakup validasi setiap field dan interaksi navigasi. Hasil pengujian menunjukkan semua skenario lulus sesuai dengan aturan yang ditetapkan.

## Kesimpulan
Pertemuan 5 memperkenalkan konsep DOM dan event handling pada JavaScript, sehingga halaman web tidak lagi bersifat statis tetapi dapat berinteraksi dengan pengguna secara dinamis.
